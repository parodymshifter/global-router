At 1× each frame holds for 0.6 s. The first pattern round is shown in 12 slices as its 2 million pieces land; every later round, slow-tier round and 3D pass is one frame. Run times are seconds since the router started.

Before layer assignment the map is the router's 2D view; from the layer-assignment frame on it sums all ten metal layers and includes via demand, so the scale shifts once there. Recording the frames leaves the routes byte-identical to a run without them.
